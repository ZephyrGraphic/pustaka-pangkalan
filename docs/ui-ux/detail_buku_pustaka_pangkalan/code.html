Sinopsis

Buku panduan komprehensif ini dirancang khusus untuk para petani dan penyuluh pertanian di pedesaan yang ingin beralih atau meningkatkan hasil panen padi organik. Menyajikan metode praktis dari persiapan lahan, pemilihan bibit unggul lokal, teknik pemupukan alami, hingga pengendalian hama terpadu tanpa bahan kimia sintetis. Dilengkapi dengan ilustrasi dan studi kasus keberhasilan desa percontohan.
